# Welcome to Phestus Stack 🚀

**Phestus** is an open-source, modular web stack and CMS ecosystem designed for high-performance web applications and modern publishing.

---

## 📦 What's in the Ecosystem?

- **[Phestus Core](./phestus)** – The core web framework and modular runtime packages.
- **[@devCMS](./phestus/tree/main/apps/dev-cms)** – A customizable, developer-first Content Management System built on Phestus.
- **Packages** – Reusable UI components, database adapters, and authentication utilities.
