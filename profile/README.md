# ⚒️ Phestus

### Build software without the box.

Phestus is a modular software ecosystem for building modern applications, services, and infrastructure.

Instead of prescribing a single architecture or locking developers into a specific provider, Phestus provides composable building blocks that can be assembled around the needs of your project.

**Modules define capabilities. Providers implement them. You decide how they work together.**

[Website](https://v1.phestus.com) · [Documentation](https://v1.phestus.com/docs) · [GitHub](https://github.com/Phestus-Stack)

### 🗄️ Phestus CMS

A modular CMS and application data layer built on the Phestus Stack.

Phestus CMS provides the infrastructure for defining application data while allowing modules to provide the behavior and functionality around it.

Build everything from traditional content-driven websites to custom applications and internal systems.

## Why Phestus?

Phestus is built around a few simple ideas.

|                       |                                                            |
| --------------------- | ---------------------------------------------------------- |
| **Modular**           | Add only the capabilities your application needs.          |
| **Extensible**        | Build your own modules, providers, and plugins.            |
| **Provider-agnostic** | Choose the technologies behind your infrastructure.        |
| **Self-hostable**     | Keep control of the software and infrastructure you build. |
| **Composable**        | Combine primitives into architectures of your own design.  |
